# Artist-Centered Platforms: a toolkit for algorithmic resistance

Here you will find resources related to the *Towards the Artist Centered Platform* workshop.

You can find the template explored in the workshop **[here](https://github.com/craigfahner/simpler-socket)**.

The completed collaborative wall project I outlined can be found **[here](https://github.com/craigfahner/coolzone)**.

Both of these projects can be forked on GitHub to be edited and expanded as you wish.

You can find some additional resources at the links above, including the "[Building Blocks of Web Apps](/tutorial.md)" tutorial from the workshop, and a list of [alternative platforms](/toolkit.md) and [artist-centered platforms](/artist_platforms.md).
