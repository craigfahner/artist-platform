# Alternative platform resources for the classroom

**[OBS.Ninja](https://obs.ninja/)**: Peer-to-peer videoconferencing

**[WebRTC](https://webrtc.org)**: Peer-to-peer communication framework

**[p5.js](https://p5js.org)**: Interactive, arts-focused Javascript programming library for the web

**[socket.io](https://socket.io)**: Communication library for building synchronous apps

**[Glitch](https://glitch.com)**: Collaborative hosting and browser-based editing for web applications

**[are.na](https://are.na)**: Collaborative link sharing platform

**[Basic Auth](https://glitch.com/~basic-auth)**: Glitch example that demonstrates how to password-protect a site using javascript
